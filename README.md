"# clone-hero-overlay-artwork-downloader" 

***THIS IS AN ENTIRELY VIBECODED PROJECT***

I created this project because I wanted a clean, easy way to have a song info overlay for streaming, that also included the album artwork. The project is created ENTIRELY with Claude, I don't know a lick of code.

To run, simply download and run the EXE. There is not installation, it's a completely portable program.

SETUP:
Point the program to the currentsong.txt file that Clone Hero generates, set a path for the program to generate the album image (if you don't want to use the built in overlay feature), and set a default image that the overlay will revert to in-between songs.
Set up your songs folder(s), set the output image size that you'd like the program to generate, then check whether you want the program to grab missing artwork from iTunes (program can be used entirely offline without this feature turned on).

BROWSER OVERLAY:
Enable or disable the browser overlay and set a port.
Choose a text and background colour for the overlay, as well as a background opacity and width.
Choose a custom font, or use the built in font.
Add idle text that the overlay will display between songs.

CUSTOMIZATION:
Choose a layout for the overlay.
Change song text size, artist text size, charter text size, scroll speed of the text, scroll pause length before looping, and idle text size.

STARTUP:
The program scans and indexes your songs folders before running, which may take some time on initial startup. After the initial index, the program should only index newelly added songs. NOTE: If you have your songs directory in a OneDrive folder, the program may have to run a new index everytime you restart.  This is due to how OneDrive touches "date modified" properties.
